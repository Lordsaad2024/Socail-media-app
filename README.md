# 📱 منصة التواصل الاجتماعي - Social Media App

منصة تواصل اجتماعية حديثة وتفاعلية تمكّن المستخدمين من مشاركة الأفكار والصور والمنشورات مع مجتمع ديناميكي، دون الحاجة إلى خدمات الدردشة المباشرة.

## 🌟 المميزات الرئيسية

### 👥 التواصل الاجتماعي
- **المنشورات والتحديثات**: انشر صورك ومشاركاتك وشارك أفكارك مع الآخرين
- **الملفات الشخصية**: انشئ ملفك الشخصي وعرّف الآخرين بنفسك
- **المتابعة والمتابعون**: تابع المستخدمين الذين تهتم بهم واستقبل متابعين جدد
- **الإعجابات والتعليقات**: تفاعل مع منشورات الآخرين من خلال الإعجابات والتعليقات البناءة

### 🔍 الاستكشاف والاكتشاف
- **تصفح المحتوى**: استكشف منشورات من المستخدمين الآخرين بسهولة
- **البحث والتصفية**: ابحث عن المستخدمين والمنشورات بكفاءة
- **الاتجاهات والنقاشات**: تابع أحدث النقاشات والاتجاهات في المنصة

### 🎨 الواجهة الرسومية
- **تصميم حديث وسهل الاستخدام**: واجهة استخدام بسيطة وجميلة
- **استجابة سريعة**: تطبيق سريع وموثوق
- **دعم الأجهزة المختلفة**: متوافق مع الهواتف الذكية والحواسيب

## 🛠 التكنولوجيا المستخدمة

- **Frontend**: 
  - JavaScript (45.5%)
  - HTML (33.7%)
  - CSS (20.8%)

## 📦 المتطلبات

- المتصفح الحديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت
- Node.js (للتطوير)

## 🚀 البدء السريع

### التثبيت

1. استنسخ المستودع:
```bash
git clone https://github.com/Lordsaad2024/Socail-media-app.git
cd Socail-media-app
```

2. ثبت المكتبات المطلوبة:
```bash
npm install
```

3. شغل التطبيق:
```bash
npm start
```

سيتم فتح التطبيق تلقائياً في المتصفح على `localhost:3000`
